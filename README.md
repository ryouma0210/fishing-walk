# Fishing Walk

位置情報・歩数・釣りを組み合わせた、サーバー不要のローカル完結型モバイルアプリです。

| 項目 | 内容 |
|---|---|
| アプリ名 | Fishing Walk |
| バージョン | 0.1.0 |
| Framework | Expo SDK 57 / React Native 0.86 |
| Language | TypeScript |
| 画面向き | 縦画面固定 |
| 保存 | SQLite、アプリ専用領域 |
| 通信 | 通常利用では不要 |
| Android | Release APK |
| iOS | EAS / TestFlight設定のみ、実機未検証 |

## 現在の機能

### 日本編・世界編・宇宙編

- 日本編と世界編はGoogle Maps上へ実際の緯度・経度で専用ピンを配置し、宇宙編は画像マップを使用
- 47都道府県を長崎県から開始し、九州・本州を北上して北海道へ到達、沖縄県を最終エリアに設定
- 日本編47エリア、世界編50エリア、宇宙編50エリアの合計147エリア
- 沖縄のヌシ捕獲で世界編、世界編最終エリア「南極」のヌシ捕獲で宇宙編を解放
- 世界編はアジアから世界各地を巡って南極へ、宇宙編は月から宇宙の果て・始まりの宇宙海へ進行
- 累計50,000歩ごとに次の都道府県を解放
- 未解放エリアは「？」、ヌシ捕獲済みは王冠、全10種発見済みは金マークを表示
- 現在選択中の都道府県には、装備中の衣装を着たFishing Walkerを表示
- エリアは開始地点を画面下、最終地点を上に置き、下から上へスクロールして進行
- 日本・世界・宇宙の地図をそれぞれ12個の高精細タイルに分割し、拡大時の画質低下を軽減
- 4エリア単位の「前へ／次へ」を廃止し、地図を上下左右へ連続スワイプして全エリアを移動
- 解放済みエリアをタップするとFishing Walkerがその地点へ移動
- タップ前から発見数・ヌシマーク・コンプマークを表示し、タップ後はエリア内10種を展開

### 魚・名産物・図鑑

- 全147エリアにE・D・C・B・A・S・SS・SSS（ヌシ）の8種と収集物2種を用意
- 日本編470種、世界編500種、宇宙編500種、合計1,470種の専用イラストを収録
- 世界編は国別の名産物、宇宙編は惑星・宙域別の未知物質を各2種用意
- 名産物は餌の種類を問わず、それぞれ0.3%の確率でヒット
- 未発見の魚・名産物は「？」で表示
- 水族館機能は廃止し、ヌシ図鑑と都道府県別図鑑へ統合
- ヌシには途切れ防止の余白を確保した専用全身イラスト47点を使用

### 釣りゲーム

- 一人称視点の竿・水面・魚影、キャスト、魚の接近ゲージ、ウキ沈下、合わせ、捕獲結果を実装
- 水面中央の魚影が左右へ泳ぎ、その動きに合わせて竿を左右へ寝かせるバトル方式
- 同じ方向のリールを長押しすると魚との距離が縮み、逆方向・放置では距離が広がる
- 時間維持や対象枠ではなく、画面上部の「魚までの残距離」を0mにすると捕獲
- 開始距離はE 30m、D 40m、C 50m、B 60m、A 75m、S 90m、SS 110m、SSS 150m
- 投げた後はエリア情報ヘッダーを隠し、距離ゲージを最上部、操作ボタンを最前面下部へ固定
- 魚ごとに小刻み・急な引き・ゆっくり抵抗・不規則移動を設定し、暴れる前に「！」を表示
- ヌシ戦は複数段階、大暴れ、専用カットイン、専用BGM、捕獲後の次エリア解放演出を用意
- 基準時間はE 15秒、D 30秒、C 45秒、B 60秒、A 90秒、S 120秒、SS 150秒、SSS 180秒。ロッドとリールで短縮

### 歩数・デイリー

- Android Health Connect／iOS Appleヘルスケアから今日と過去の日別歩数を同期
- 今日・月間グラフ、月間カレンダー、合計・平均・最高記録を表示
- カレンダーの日付下に歩数を表示し、日曜日は赤、土曜日は青で表示
- 権限拒否やHealth Connect未インストール時もアプリを停止させず案内を表示
- デイリー達成報酬としてE～Sランクの餌を獲得可能
- 起動・再起動時に本日の歩数と獲得ポイントを表示

### プレイヤーレベル

- 魚を捕獲するたびにランク別経験値を獲得（E 10、D 15、C 22、B 32、A 46、S 65、SS 90、SSS 140 EXP）
- 最大レベルはLv100で、レベルが高くなるほど次のレベルに必要な経験値が増加
- 通常のレベルアップで巻き取り性能+0.1%、Lv5・10・15…の5倍数では+0.5%
- Lv100時の累計巻き取り補正は+17.9%
- マイページにレベル、経験値ゲージ、次レベルまでのEXP、巻き取り補正を表示
- 捕獲結果に獲得EXPとLEVEL UP演出を表示

### 交換・装備

- 交換通貨は歩数ポイントのみ（100歩＝1pt）。釣果からポイントは付与しない
- 交換画面の先頭で「衣装一式・ロッド・リール・餌・クーラー」のカテゴリを選択
- 帽子・服・ズボン・靴は個別購入せず、完成した衣装一式として交換
- 餌は1～10個をまとめて購入でき、使用ごとに1個消費
- クーラーは一日の釣果上限を50・100・500・1,000匹へ拡張
- マイページから交換済みの衣装一式・ロッド・リール・クーラーを変更可能
- ロッドは必要時間、リールは対象ゲージと必要時間、衣装は魚の速度と最大サイズに反映
- STG環境では動作確認用に9,999ptを付与

### サウンド・設定・保存

- エリア、通常釣り、通常バトル、ヌシ戦、捕獲結果、図鑑・マイページ、交換画面のBGMを収録
- リール、糸の張り、水しぶき、捕獲、逃走の効果音と端末振動を実装
- 音量、消音、振動、演出速度、文字サイズを設定可能
- 釣果、捕獲場所・日時・サイズ、自己ベスト、ポイント消費、装備、日別歩数をSQLiteへ保存
- データの書き出し・復元、権限状態確認、歩数再同期を用意

> 歩数・釣果・装備情報は外部サーバーへ送信しません。通常のゲーム利用は端末内で完結します。

ゲーム用イラストは `assets/game/`、BGM・効果音は `assets/audio/` に格納しています。日本編は `assets/game/prefectures/`、世界編は `assets/game/world/`、宇宙編は `assets/game/space/`、日本編のヌシ全身画像は `assets/game/prefecture-bosses/` にあります。

## 開発

### Androidシミュレーターで画面を確認する

初回のみ依存パッケージをインストールします。

```powershell
npm install
```

Android Studioで作成した仮想端末を起動し、Fishing WalkをExpo Goで開きます。

```powershell
npm run simulator
```

このコマンドはAndroid SDKと利用可能な仮想端末を検出し、次の処理を自動で行います。

- 停止中のAndroidエミュレーターを起動
- `offline` 状態のADB接続を再起動
- Androidの起動完了まで待機
- Expoのキャッシュを消去してFishing Walkを表示

起動後はTypeScript／TSXファイルを保存すると画面へ自動反映されるため、シミュレーターを見ながらレイアウトを調整できます。終了するときはExpoを起動したターミナルで `Ctrl+C` を押してください。

通常のExpo開発サーバーだけを起動する場合は、次を使用します。

```powershell
npm start
```

### コード確認

```powershell
npm run typecheck
npm run lint
```

> Expo Goでは画面レイアウトと通常ゲーム機能を確認できます。Health Connectなどのネイティブ機能を確認する場合は、Release APKまたはDevelopment Buildを使用してください。

## Google Maps

日本編は47都道府県庁所在地、世界編は50地域の代表地点へ専用ピンを表示します。宇宙編は星ごとの画像マップを使用します。独自バックエンドは不要ですが、日本編・世界編の地図表示にはインターネット通信が必要です。

Google Maps SDKキーは `react-native-maps` のExpo Config Pluginへ設定しています。Release APKでは、Google Cloud側のキー制限にAndroidパッケージ名 `jp.local.fishingwalk` とAPK署名証明書のSHA-1を登録してください。

## ブランチとAPK

| ブランチ | 用途 | APK |
|---|---|---|
| `main` | 開発 | 自動生成なし |
| `stg` | STG | `fishing-walk-stg.apk` |
| `production` | PRD | `fishing-walk-prd.apk` |

`stg` / `production`へのpushでGitHub ActionsがRelease APKを作成し、Artifactと指定Google Driveフォルダへアップロードします。Repository secret `GDRIVE_RCLONE_CONFIG_BASE64` に、remote名が `gdrive` のrclone設定をBase64で登録してください。

## 注意

- AndroidはHealth Connect、iOSはAppleヘルスケアの「歩数を読み取る」権限が必要です。許可後はアプリ起動前の歩数も同期します。
- Health Connect／HealthKitはネイティブ機能のため、歩数連携の実機確認にはExpo GoではなくAPKまたはDevelopment Buildが必要です。
- iOSビルド・TestFlightにはApple Developer設定とEAS project IDの設定が必要です。
- APKの継続アップデートには固定した署名鍵を安全に管理してください。
- 470点の画像によりpushデータが大きくなっています。HTTP 408になる場合はHTTP/1.1で再試行し、継続する場合は画像のGit LFS移行を検討してください。
